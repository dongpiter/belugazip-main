## 7. API ROUTES

### `/api/notify-lead` (POST)

```typescript
export async function POST(request: Request) {
  const body = await request.json(); // đọc MỘT LẦN duy nhất
  const {
    menu_name, menu_price, guest_count, service_type,
    customer_name, phone, email, source_page,
    event_date, event_time, address, notes,
    utm_source, utm_medium
  } = body;

  const supabase = createSupabaseAdmin(); // service_role

  // 1. Lưu lead
  await supabase.from('leads').insert({
    menu_name, menu_price, guest_count, service_type,
    customer_name, phone, email, source_page, utm_source
  });

  // 2. Tính giá và lưu order
  const { data: menu } = await supabase
    .from('menus').select('id, price_per_person').eq('name', menu_name).single();

  const subtotal = (menu?.price_per_person ?? 0) * (guest_count ?? 0);
  const service_fee = Math.round(subtotal * 0.1);

  await supabase.from('orders').insert({
    customer_name, phone, email, service_type,
    menu_id: menu?.id, guest_count, event_date, event_time,
    address, notes, subtotal, service_fee,
    total_amount: subtotal + service_fee,
    utm_source, utm_medium, source_page, status: 'pending'
  });

  // 3. Upsert customer + cộng điểm
  await supabase.from('customers').upsert(
    { name: customer_name, phone, email,
      total_orders: 1, loyalty_points: Math.floor((subtotal + service_fee) / 10000) },
    { onConflict: 'phone',
      ignoreDuplicates: false }
  );

  // 4. Trigger AI lead scoring (fire & forget)
  fetch(`${process.env.NEXT_PUBLIC_SITE_URL}/api/ai/score-lead`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ menu_name, guest_count, service_type, phone, email, notes })
  }).catch(() => {});

  return Response.json({ success: true });
}
```

```
Cuối mỗi câu trả lời có lead intent, thêm: "Để đặt tiệc, vui lòng để lại SĐT nhé!"
Trả lời ngắn gọn, thân thiện, dùng tiếng Việt.
```

- Dùng `streamText` từ `ai` SDK
- Lưu mỗi turn vào bảng `chat_sessions` (session_id từ cookie anonymous)
- Nếu user để lại SĐT trong chat → tự động INSERT vào `leads`

### 8.2 AI Menu Recommender — `/api/ai/recommend-menu` (POST)

Input: `{ guests: number, occasion: string, budget: number, preferences: string[] }`

Xử lý:
1. Fetch toàn bộ menus từ Supabase (id, name, category, price_per_person, tag, description)
2. Gửi lên AI với prompt: "Dựa trên thông tin khách hàng và danh sách menu sau, chọn 3 menu phù hợp nhất. Trả về JSON array: [{menu_id, menu_name, reason, match_score}]"
3. Parse JSON response → return 3 menu objects kèm lý do

### 8.3 AI Tạo Draft Blog — `/api/ai/generate-blog` (POST, admin-only)

Input: `{ topic: string, keywords: string[], category: string }`

Output (JSON):
```json
{
  "title": "...",
  "meta_title": "...",
  "meta_description": "...",
  "excerpt": "...",
  "content": "<h2>...</h2><p>...</p>...",
  "tags": ["..."],
  "reading_time": 4
}
```

- Dùng `claude-opus-4-5` cho chất lượng cao
- INSERT vào `blog_posts` với `is_published = false`
- Toast: "Draft đã được tạo! Kiểm tra trong /admin/blog"

### 8.4 AI Lead Scoring — `/api/ai/score-lead` (POST, internal)

Input: `{ menu_name, guest_count, service_type, phone, email, notes }`

Logic AI:
- **hot**: guest_count ≥ 50, hoặc service_type = 'event', hoặc notes chứa từ như "gấp", "tuần này", "khai trương"
- **warm**: guest_count 20-49, hoặc có email doanh nghiệp
- **cold**: guest_count < 20, không có email

Output: `{ score: 'hot'|'warm'|'cold', reason: string }`

Update bảng `leads` với `ai_score` + `ai_score_reason`.

### 8.5 AI Email Báo Giá — `/api/ai/quote-email` (POST, admin-only)

Input: `{ order_id: string }` → fetch order + menu details từ Supabase

Output: Email tiếng Việt chuyên nghiệp gồm:
- Lời chào, tóm tắt yêu cầu
- Bảng báo giá chi tiết (menu, số khách, đơn giá, phí dịch vụ, tổng)
- Điều khoản đặt cọc, hủy
- CTA liên hệ xác nhận

### 8.6 AI Weekly Insight — `/api/ai/weekly-insight` (GET, cron)

Chạy mỗi thứ Hai 8:00 sáng (cấu hình Replit Scheduled Jobs hoặc Vercel Cron).

Logic:
1. Query Supabase: đơn hàng 7 ngày qua, doanh thu, top menus, top lead sources
2. So sánh với 7 ngày trước đó
3. Gửi data lên AI: "Phân tích và viết 3 insight ngắn + 2 gợi ý hành động cho BELUGA Catering"
4. Lưu kết quả vào `site_settings` key `weekly_insight`
5. Hiển thị trong admin dashboard
